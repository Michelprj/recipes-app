# Recipes App

## Deploy do projeto
https://recipes-app-nine-eta.vercel.app/

## Descrição

O Recipes App é um aplicativo de receitas desenvolvido como parte do módulo Front-end do curso de Desenvolvimento Web Full-stack da Trybe. O projeto foi realizado em grupo utilizando as metodologias ágeis Scrum e Kanban.

O aplicativo permite que os usuários visualizem receitas de comidas e bebidas, pulem para etapas de receitas prontas e favoritem novas receitas.

## Tecnologias Utilizadas

- **React**: Biblioteca JavaScript para construção de interfaces de usuário.
- **Context API**: Gerenciamento de estado global no React.
- **Bootstrap**: Framework CSS para desenvolvimento responsivo e estilização.
- **CSS**: Linguagem de estilo utilizada para customizações adicionais.

## Funcionalidades

- **Visualização de Receitas**: O usuário pode navegar por diversas receitas de comidas e bebidas.
- **Favoritar Receitas**: Os usuários podem marcar suas receitas favoritas para fácil acesso posterior.
- **Etapas de Receitas**: O usuário pode pular para etapas de receitas já prontas.

## Metodologias Ágeis

O desenvolvimento do projeto seguiu as metodologias Scrum e Kanban para garantir uma organização eficiente e uma entrega contínua de valor:

- **Scrum**: Utilizamos sprints para definir e cumprir metas de desenvolvimento em intervalos regulares.
- **Kanban**: Utilizamos um quadro Kanban para visualizar o fluxo de trabalho e gerenciar tarefas de forma eficaz.

## Como Executar o Projeto

Para rodar o projeto localmente, siga os passos abaixo:

1. Clone o repositório:
 ```
   git clone https://github.com/Michelprj/recipes-app.git
```
2. Instale as dependências:
```
  cd recipes-app
  npm install
```
3. Execute o projeto:
```
  npm start
```
O aplicativo estará disponível em http://localhost:3000.
